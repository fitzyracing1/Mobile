# Belarus Freedom Project

Anti-censorship toolkit for bypassing internet restrictions and accessing blocked content.

## Features

- **Web Blocking Detection**: Data mining and pattern analysis to identify blocking attempts
- **Circumvention Tools**: Multiple strategies to bypass censorship
- **YouTube Access**: Specialized methods for accessing video platforms

## Components

- `detector/` - Blocking detection and analysis
- `circumvention/` - Proxy, VPN, and tunneling tools
- `data_mining/` - Pattern analysis and ML-based evasion
- `youtube_access/` - Specialized YouTube unblocking methods

## Quick Start

```bash
pip install -r requirements.txt
python main.py --detect --circumvent
```
